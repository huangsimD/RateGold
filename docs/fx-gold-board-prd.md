## 0. 一句话

> **FxGold Board** 帮 SEA/南亚/中东用户在没有稳定网络时，也能一眼看到 **常用货币汇率** 和 **本地金价**，并快速换算汇款、购物、买金饰——比打开浏览器搜、比功能臃肿的理财 App 更轻、更快。

## 1. Problem Statement



### 1.1 谁在痛？


| Persona         | 背景                      | 频率          | 不解决的代价              |
| --------------- | ----------------------- | ----------- | ------------------- |
| **Rina**（印尼）    | 在 Dubai 打工，每月寄钱回家       | 每周查 2–3 次汇率 | 选错汇款时机，损失等值 $5–20/笔 |
| **Arjun**（印度）   | 家庭买金饰，关心 24K 金价         | 节日前后每天看     | 被金店报价忽悠，多付 2–3%     |
| **Fatima**（UAE） | 外籍主妇，多币种生活（AED/USD/PHP） | 超市/网购前随手查   | 心算错误，超支或买贵          |
| **Marco**（菲律宾）  | 旅游/代购，离线航班/偏远岛          | 出行时无网       | 无法估价，被迫用黑市中间价       |




### 1.2 现有方案为何不够好？


| 方案          | 问题                        |
| ----------- | ------------------------- |
| Google 搜索   | 需联网；无收藏；金价与汇率分离           |
| XE / 银行 App | 功能多但重；部分市场金价单位不友好         |
| 系统小组件       | 不可离线；币种固定                 |
| 华人汇率 App    | 主战场中国，SEA/MENA 币种与金价单位覆盖差 |




### 1.3 我们的差异化（V1）

1. **离线优先**：上次同步数据本地可读，明确标注「截至 xx:xx」
2. **汇率 + 金价同一屏**：面向 SEA/南亚/海湾用户心智
3. **零账号、零广告（V1）**：安装即用，隐私友好（Data Safety 简单）
4. **轻量**：单核心路径 < 3 次点击完成换算

## 4. Information Architecture

```
Bottom Nav (3 tabs):
  Board (default) | Convert | Settings

Board:
  ├─ Sync status bar（在线/离线 + 最后更新）
  ├─ Gold strip（横向：主市场金价）
  ├─ Rates list（收藏货币对 + 24h 变化占位*）
  └─ [V1.1] 728 变化需历史 API，V1 可仅显示汇率值

Convert:
  ├─ From currency + amount
  ├─ To currency
  └─ Result + swap

Settings:
  ├─ Base currency
  ├─ Manage favorites（最多 8 个）
  ├─ Sync now
  └─ About / Privacy / Data source credits
```

## 5. Data & Offline Strategy



### 5.1 数据源（V1 推荐）


| 数据         | 来源                                                            | 说明                        |
| ---------- | ------------------------------------------------------------- | ------------------------- |
| 法币汇率       | [Frankfurter API](https://www.frankfurter.app/)               | 免费、无 Key、ECB 日频，适合 MVP    |
| 金价（USD/oz） | [GoldAPI.io](https://www.goldapi.io/) 免费档 / 或 bundled 日更 JSON | 免费档 100 req/月 → **必须强缓存** |
| 备用         | App 内置 `assets/rates_seed.json`                               | 首次安装 / API 全挂时兜底          |




### 5.2 本地存储

- `shared_preferences`：基准货币、收藏列表、最后同步时间  
- `hive` 或 JSON 文件：最新 rates snapshot + gold snapshot  
- 同步策略：App 启动若有网则后台刷新；用户下拉强制刷新；**最少间隔 15 分钟**（省 API 配额）



### 5.3 离线语义（对用户诚实）

- 显示：**「Offline · Rates as of 2 Jul, 09:41 GST」**  
- 禁止：无数据时伪造「实时」  
- 金价若超过 24h 未更新，卡片琥珀色提示
