# Version Plan（版本迭代计划）

本目录专门存放 **每一次版本迭代** 的功能清单与功能描述，作为 V1.1 及之后迭代的权威记录。

## 命名约定

| 文件 | 用途 |
|------|------|
| `README.md` | 本说明 + 版本索引 |
| `v1.1.0.md` | 版本 `1.1.0` 的功能清单与描述 |
| `v1.2.0.md` | 下一版本（开启时新建） |

文件名使用 **`v` + versionName**（与 `pubspec.yaml` / Play versionName 对齐）。

## 每份版本文档应包含

1. **版本元信息**：versionName / versionCode、相对现网、发布策略  
2. **范围与不做项**  
3. **功能点清单**（表格：模块 / 功能 / 简述 / 状态）  
4. **功能描述**（每个功能点的目标、行为、验收、依赖）  
5. **变更日志**（按日追加）

## 状态图例

| 状态 | 含义 |
|------|------|
| 规划中 | 已定范围未开工 |
| 开发中 | 代码进行中 |
| 测试中 | 仅 Closed / Internal testing |
| 已上线 | 已进 Production |
| 暂缓 | 本版本不做 |

## 维护约定（Agent / 人工）

凡修改 App、Ops、构建或上架相关行为，必须同步更新 **当前目标版本** 文件（如 `v1.1.0.md`）：补清单行、改状态、写变更日志。  
开启新 versionName 时：新建 `vX.Y.Z.md`，并在下方索引登记；不要覆盖旧版本文档。

旧路径 [`docs/下版本上线功能点-1.1.0.md`](../docs/下版本上线功能点-1.1.0.md) 仅作跳转，**以本目录为准**。
